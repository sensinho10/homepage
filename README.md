# Archiv — alte Adresse der digitalen Visitenkarte

Dieses Repository hat bis August 2026 unter
`https://sensinho10.github.io/homepage/` eine digitale Visitenkarte
ausgeliefert. Sie enthielt inzwischen **veraltete Kontaktdaten**
(alte Mobilnummer, private E-Mail-Adresse) und wurde deshalb entfernt.

Alle Seiten leiten jetzt auf **https://senser-ki.de** weiter, damit
bereits verteilte QR-Codes weiterhin bei den aktuellen Daten landen.

Die gepflegte Website liegt im privaten Repository `sen-os` und wird
per FTPS zu Hetzner ausgeliefert — nicht über GitHub Pages.
